# EzPTable

[English](https://github.com/VVinCentZhang/EzPTable/blob/main/README.md) · [简体中文](https://github.com/VVinCentZhang/EzPTable/blob/main/README.zh-CN.md) · [繁體中文](https://github.com/VVinCentZhang/EzPTable/blob/main/README.zh-TW.md) · [**日本語**](https://github.com/VVinCentZhang/EzPTable/blob/main/README.ja.md)

> ニューモーフィズム（Neumorphism）のデザイン、多言語対応、フルスクリーン 3D 電子軌道クラウドを備えたインタラクティブな周期表。

EzPTable は **単一ファイル・ビルド不要** の Web アプリケーションです。データ・スタイル・ロジックのすべてが 1 つの HTML ファイルに収められており、ブラウザで直接開くか、任意の静的ホスティングに配置するだけで動作します。

---

## ✨ 機能

| 機能 | 説明 |
| --- | --- |
| 🧪 **完全な元素データ** | 全 118 元素を収録。原子番号、原子量、電子配置、電気陰性度、融点、沸点、密度、発見年、酸化数を網羅 |
| 🌐 **多言語対応** | 日本語・简体中文・繁體中文・English をリアルタイムで切り替え |
| 🎨 **デュアルテーマ** | ニューモーフィズムのライト / ダークテーマ。円形リビールで滑らかに遷移 |
| 🌡️ **温度スライダー** | −273 °C から 6000 °C までドラッグし、元素の状態変化をリアルタイムに確認 |
| 🎯 **カテゴリ絞り込み** | カテゴリ別に元素を絞り込み（アルカリ金属、希ガス、ランタノイド、アクチノイドなど） |
| 🔍 **インスタント検索** | 元素名・記号・原子番号で検索可能 |
| ⭐ **お気に入り** | 元素をフォルダにドラッグして保存。左スワイプまたは右クリックで削除。長押しで一括クリア |
| 🔖 **元素詳細** | 3D チルト・グレア・電子殻アニメーションを備えたモーダル。モバイルではジャイロスコープ対応 |
| ⚛️ **電子軌道クラウド** | 30 軌道（n = 1〜4）を収録したフルスクリーン 3D 電子確率密度ビューア。10 種類のカラーパレット、ダーク / ライトテーマ同期 |
| ☕ **コーヒーボタン** | パチンコ風のボタンからサポート用モーダルを表示 |

## 🎮 使い方

### 周期表

- **検索** — 検索ボックスに元素名・記号・原子番号を入力して絞り込み
- **言語切替** — ヘッダーの 简 / 繁 / EN / 日 をクリック
- **テーマ切替** — 太陽 / 月アイコンをクリックすると、ボタンから円形リビールが展開
- **温度調整** — スライダーをドラッグして状態変化を確認。**−273 °C**・**室温**・**リセット** のショートカットも利用可能
- **状態で着色** — 「状態で着色」スイッチをオンにすると、固体 / 液体 / 気体でカードが着色される
- **カテゴリ絞り込み** — 凡例行のカテゴリチップをクリック
- **詳細表示** — 任意の元素カードをクリック。モーダルがカーソルに合わせて 3D チルト
- **お気に入り管理** — 元素をフォルダにドラッグして保存。左スワイプまたは右クリックで削除。3 件以上でゴミ箱ボタンを長押しすると全消去

### 電子軌道クラウド

- **開く** — ヘッダーの軌道アイコンをクリック
- **軌道を選択** — 下部パネルで主量子数 *n* ごとにグループ化された軌道から選択
- **パレット切替** — 右上の 10 個のカラースウォッチから選択
- **テーマ切替** — 太陽 / 月ボタンをクリック。周期表のテーマも同期して切り替わる
- **回転 / ズーム** — ドラッグで回転、スクロールまたはピンチでズーム。視点はゆっくり自動回転

## 💻 ローカルでの実行

ビルドツールや依存関係は不要です。クローンしてそのまま開けます：

```bash
git clone https://github.com/VVinCentZhang/EzPTable.git
cd EzPTable
# EzPTable.html をブラウザで直接開くか、ローカルサーバーを起動：
python3 -m http.server 8000
# その後 http://localhost:8000/EzPTable.html にアクセス
```
